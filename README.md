## Использование
1. Разархивируйте файлы проекта в свою рабочую папку
2. Установите библиотеку Poetry из репозитория Git через команду в терминале 
(у вас должна быть версия Python 3.13 или старше)
```
curl -sSL https://install.python-poetry.org | python3 - --git https://github.com/python-poetry/poetry.git@main
```

3. Откройте проект через программу PyCharm


## Разработка
В каждом файле .py в папке src есть закомментированные строки с тестовыми входными данными в функции и их вызовом.
Для тестирования функций достаточно раскомментировать строки и запустить файлы нажав на кнопку Run

## Декоратор `log`

log — это декоратор для Python, предназначенный для логирования начала и конца выполнения функции, а также результатов её работы или возникших ошибок. Декоратор может записывать логи как в консоль, так и в файл.

### Как использовать

```python
from src.decorators import log

@log()
def my_function(arg1, arg2):
    # Код функции
    pass

Аргументы
 • filename (опционально): Строка с именем файла, куда будут записываться логи. Если не указано, логи выводятся в консоль.

Поведение
 • При успешном выполнении функции декоратор логирует сообщение о начале и окончании выполнения функции.
 • Если в функции возникает исключение, декоратор логирует сообщение об ошибке с указанием типа исключения и аргументов функции.

Пример

@log()
def divide(a, b):
    return a / b

divide(10, 2)  # Логирование успешного выполнения
divide(10, 0)  # Логирование исключения ZeroDivisionError
```

## Тестирование
Установите библиотеку pytest-cov:
```
poetry add --group dev pytest-cov
```
После установки библиотеки, введите команду в треминале для запуска тестов с подробным отчетом:
```
pytest -vv
```
для генерации отчета о покрытии тестами модулей введите в терминал:
```
poetry run pytest --cov
```

Начиная с файла generators.py в конце кода появляется ветка:
```
if __name__ == '__main__':
```
Для проверки функций и работы генераторов достаточно раскоментировать всю ветку main
и входные данные, которые находятся сразу после импорта (вверхку файла)
Далее после запуска команды в терминале всё будет работать:
```
python3 src/generators.py
```

## Декоратор `log`
Тест для декоратора log проверяет корректность обработки исключений и логирования с использованием pytest. Тесты находятся в файле test_decorators.py.

Установка зависимостей

Перед запуском тестов установите зависимости с помощью pip:

pip install -r requirements.txt

Запуск тестов

Для запуска тестов используйте команду:

pytest

Пример теста

import pytest
from src.decorators import log, my_function

@log()
def test_log_is_None_negative_zero_console(capsys):
    with pytest.raises(ZeroDivisionError) as excinfo:
        my_function(1, 0)
    
    captured = capsys.readouterr()

    assert "my_function завершилась с ошибкой: ZeroDivisionError: division by zero" in captured.err
    assert "Входные параметры функции: (1, 0), {}" in captured.err
    assert str(excinfo.value) == "division by zero"

Этот тест проверяет, что:
 • Исключение ZeroDivisionError правильно обрабатывается и логируется.
 • Сообщения об ошибке содержат корректную информацию о типе исключения и аргументах функции.
